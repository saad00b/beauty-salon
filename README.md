# Beauty Salon X - Landing Page

A responsive landing page for a fictional beauty salon, built with **HTML**, **Tailwind CSS**, and **vanilla JavaScript**. This project showcases a full-featured one-page website, demonstrating layout, styling, and interactivity skills without using frameworks like React.

---

## Live Demo

[View the live site](https://saad00b.github.io/beauty-salon/)

---

## Features

- Fully responsive layout for desktop
- Hero section with call-to-action
- About section describing the salon
- Image gallery showcasing services
- Services section with expandable/collapsible details
- Testimonials section
- FAQ accordion
- Contact form with email input fields
- Embedded Google Map showing salon location
- Working opening hours section
- Footer with contact info and quick actions

---

## Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Google Maps embed
